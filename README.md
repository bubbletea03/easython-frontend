**음성으로 물건을 찾고, 화면·음성·진동으로 손의 이동 방향을 안내받는 모바일 웹 앱입니다.**

카메라 영상에서 찾을 물체와 손을 추적하고, 폰 방향 맞추기부터 손 뻗기까지 단계별로 안내합니다. React 19 · TypeScript · Vite로 구현했으며, 물체 탐지·명령 해석·설명·TTS를 제공하는 외부 백엔드 API와 연결합니다.

## 주요 기능

| 기능 | 동작 |
| --- | --- |
| 음성으로 물건 찾기 | 말하기 버튼을 누르고 찾을 물건을 말하면 탐색을 시작합니다. |
| 물체 탐지와 추적 | 백엔드 YOLOE 탐지를 우선 사용하고, 서버 탐지를 사용할 수 없으면 기기 내 EfficientDet Lite0로 대체합니다. |
| 손 이동 안내 | MediaPipe로 손을 추적하고 가장 크게 보이는 손 하나를 기준으로 이동 방향을 안내합니다. |
| 잡을 위치 갱신 | 서버가 추정한 잡을 위치를 물체 움직임에 맞춰 갱신하고, 잡는 방법을 안내합니다. |
| 위험 안내 | 날카로운 대상의 손잡이를 먼저 확인하고, 손이 추정 칼날 구역에 들어가면 화면·음성·진동으로 경고합니다. |
| 탐색 중지 | 탐색·처리 중에는 말하기 버튼이 **그만**으로 바뀌며, 누르면 안내와 진행 중 요청을 멈춥니다. |

## 사용 흐름

1. **시작** — 시작 버튼을 눌러 카메라와 음성 안내를 준비합니다.
2. **찾기** — 말하기 버튼을 누르고 “컵 찾아줘”처럼 찾을 물건을 말합니다.
3. **맞추기** — 폰을 돌리라는 좌우 안내에 따라 물건을 화면에 맞춥니다.
4. **손 뻗기** — 손 안내 단계에 들어가면 폰을 유지하고, 안내 방향에 따라 손을 움직입니다.
5. **안내 종료** — 화면에서 손과 목표 위치가 맞으면 “거기예요. 아직 닿지 않았다면 손을 조금 더 뻗어 보세요.”를 끝까지 재생한 뒤 탐색과 안내를 종료합니다.

탐색 중에는 **그만** 버튼으로 언제든 중지할 수 있습니다. 대기로 돌아온 뒤 말하기 버튼을 누르면 새 명령을 받습니다. 화면에서 손과 물체가 겹치는 것은 실제로 잡았다는 판단에 사용하지 않습니다.

## 기술 스택

브라우저는 화면·카메라·손 추적·방향 계산·음성 출력을 담당하고, 외부 백엔드는 물체 탐지·음성 명령 해석·설명·TTS를 담당합니다.

| 영역 | 기술 | 역할 |
| --- | --- | --- |
| 화면과 상태 관리 | React 19 | 시작 화면, 카메라 HUD, 찾기 → 맞추기 → 손 뻗기 상태 표시 |
| 타입과 안내 계산 | TypeScript 5.9 | 좌표 변환, 상대 위치·방향 계산, API 응답 타입 정의 |
| 개발·빌드 | Vite 7 | 개발 서버, HTTPS 개발 모드, 프로덕션 번들 생성 |
| 모바일 UI | CSS · 디자인 토큰 | 반응형 배치, 상태별 색상·아이콘, 안내 패널과 버튼 |
| 영상 입력 | Camera · Canvas | 카메라 미리보기와 탐지·설명 요청용 프레임 캡처 |
| 기기 내 추론 | MediaPipe · Web Workers · WASM | 손 관절·손끝 추적과 서버 탐지 실패 시 EfficientDet Lite0 실행 |
| API 통신 | Fetch API | 탐지·명령 해석·설명·TTS 요청, 취소와 오류 처리 |
| 음성·피드백 | Web Speech API · Web Audio API · Vibration API | 음성 입력, 안내 재생, 효과음과 진동 |
| 외부 백엔드 | YOLOE · 명령 해석·설명·TTS API | 찾을 물체 탐지, 명령 해석, 잡는 방법·위험 정보와 음성 생성 |
| 배포 | Vercel | 정적 자산 제공과 같은 출처의 `/api` 중계 |

카메라 프레임은 브라우저에서 캡처해 Fetch API로 백엔드에 전송합니다. 손 추적은 브라우저의 Web Worker에서 처리하며, 탐지 결과와 손끝 좌표를 같은 화면 좌표계로 변환해 안내 방향을 계산합니다. 음성은 **고정 녹음 → 서버 TTS → 브라우저 TTS** 순서로 대체합니다.

## 설정과 실행

Node.js 24와 npm을 사용합니다. 아래 명령은 Windows PowerShell 기준입니다.

Vercel 자동 배포는 [배포 설정 안내](docs/deployment.md)를 참고하세요. Vercel의 Git 연동으로 push마다 테스트·빌드·모델 자산을 검사한 뒤 배포합니다. GitHub Actions나 배포 Secrets 없이 Vercel에서 저장소를 연결하면 됩니다.

`.env.example`을 `.env.local`로 복사해 실제 백엔드 주소를 `BACKEND_API_URL`, 백엔드 API_KEY를 `BACKEND_API_KEY`에 설정하세요. `VITE_API_BASE_URL=/api`를 사용하면 키를 브라우저 번들에 넣지 않고 Vite/Vercel 서버에서 요청에 추가합니다. 실제 키는 커밋하지 마세요.

```powershell
npm.cmd ci
npm.cmd run dev -- --mode https --port 5173
```

휴대폰은 PC와 같은 Wi-Fi에서 출력되는 Network HTTPS 주소로 접속합니다. 기본 `/api` 프록시는 PC의 `http://127.0.0.1:8000`에 연결하므로 휴대폰의 루프백 주소를 사용하지 않습니다.

```powershell
npm.cmd test
npm.cmd run build
node scripts/check-build.mjs dist
npm.cmd run preview -- --mode https --port 4173
```

## UI 미리보기

개발 서버 실행 후 `/dev/preview.html?state=guiding`에서 손 안내 화면을 확인할 수 있습니다. `state` 없이 열면 상태 목록이 나오며, `&bg=bright`를 추가하면 밝은 배경으로 확인할 수 있습니다. 미리보기는 고정 데이터로 렌더링하며 프로덕션 빌드에는 포함되지 않습니다. 실제 앱 URL에 `#dev`를 붙이면 개발 정보 패널이 표시됩니다.

## 안내 동작과 사용 조건

- 시작을 누르면 카메라와 음성 안내를 준비합니다. 대기 중에는 물체 탐지·마이크·프레임 업로드를 하지 않으며 손 모델만 미리 준비합니다.
- **버튼을 누를 때만 한 번 듣습니다.** 탐색 중 계속 듣기는 꺼져 있습니다. 말이 끝나거나 버튼을 다시 누르면 마이크가 꺼집니다. 말이 없으면 5초, 전체 녹음은 최대 6초이며 자동으로 다시 켜지지 않습니다. 앱 녹음 시작·종료 효과음은 없고 종료 진동만 있습니다.
- 탐색·처리 중에는 음성 버튼이 **그만** 버튼으로 바뀝니다. 누르면 안내·비프·진행 중 요청을 즉시 멈추고 대기로 돌아갑니다. 대기 상태에서 다시 말하기 버튼을 누르면 새 음성 명령을 받습니다.
- 손 안내에 들어가기 전에는 폰 좌우 방향만 안내합니다. 물체가 가운데에 0.5초 머물거나 손이 0.5초 보이면 손 안내를 잠급니다. 손 안내 중 폰이 조금 흔들려도 다시 조준으로 돌아가지 않습니다. 좌우 가장자리 10%를 넘으면 “손은 그대로 두고, 폰을 …”으로 전환하고, 안쪽 25~75%로 돌아오면 “다시 손을 안내할게요”라고 말합니다.
- 손 안내 방향은 “왼쪽·오른쪽·앞으로·몸 쪽으로”입니다. 화면에서 손과 목표 위치가 맞으면 “거기예요. 아직 닿지 않았다면 손을 조금 더 뻗어 보세요.”와 진동 [80]을 안내합니다. 이 음성이 완전히 끝나면 탐색과 안내를 종료하고 대기로 돌아갑니다. 실제로 잡았다고 판단하지 않습니다.
- 칼·가위·면도기·손톱깎이 또는 AI의 sharp 위험 대상은 손잡이를 확인하기 전 박스 가운데로 손을 유도하지 않습니다. 즉시 손잡이 확인을 요청하고 손을 잠시 멈추도록 알립니다. 손잡이 반대쪽 절반을 칼날 쪽으로 추정하며, 손끝이 이 구역에 0.3초 머물면 음성·진동 [400·150·400]·경고 화면으로 알립니다. 반복은 최소 4초 간격이며 손이 벗어나면 해제합니다. 이 구역은 영상 기반 추정이며 실제 칼날·접촉을 확인하는 기능은 아닙니다.
- 서버 탐지는 신뢰도 0.5 이상을 사용하고 정확한 이름 일치 → 신뢰도 → 크기 순으로 대상을 고른 뒤 고정합니다. 비슷한 두 후보를 구별하지 못하면 선택 안내가 끝난 뒤 5초 후 더 크게 보이는 쪽을 자동 선택합니다. 짧은 누락은 2초 유지하며, 서버가 3회 연속 실패하면 대체 인식 후 5초마다 서버 복구를 확인합니다.
- 자동 설명은 손 안내를 멈추지 않는 백그라운드 요청입니다. 잡는 법은 손 안내 시작 후 한 번만 말하고, 좌표는 물체 움직임을 따라가며 10초 간격으로 재요청합니다. 캡처에는 25% 여백을 둡니다. 그만 버튼을 누르면 탐색과 진행 중 요청을 취소합니다.
- **시작한 음성 안내는 끝까지 재생합니다.** 다음 안내는 현재 안내가 끝날 때까지 기다리며, 화면의 안내 메시지도 재생 중인 음성에 맞춰 유지합니다. 사용자가 그만 버튼을 누르거나 페이지를 숨기면 즉시 취소할 수 있습니다.
- 녹음·서버 TTS는 공용 Web Audio 컨텍스트로 재생하며 실패 시 미디어 요소·브라우저 TTS로 대체합니다. TTS·디코딩 버퍼를 캐시합니다. #dev에서 실제 이름·음성 종료 이유·재생 경로를 확인할 수 있습니다. 지원 브라우저에서는 카메라가 켜진 동안 Wake Lock을 유지합니다.
