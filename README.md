# 손길 · 물건 찾기 프론트엔드

## 최신 구현 상태

현재 화면은 전체 화면 카메라, 하단 음성 인식 버튼, 브라우저 내 물체 탐지로 구성됩니다.
손·손가락 추적, 가장 큰 물체 선택, 상대 방향·화면상 간격의 음성 안내도 지원합니다. 요구사항별 완료 범위와 그립 기능의 미구현 사항은 [프론트엔드 요구사항](docs/frontend-requirements.md)에 정리했습니다.
MediaPipe EfficientDet-Lite0으로 COCO 80종을 자동 탐지하고 한국어 이름·신뢰도·위치 상자를 표시합니다.
영상은 별도 Web Worker에서 처리하며 서버로 전송하지 않습니다. 음성 인식 결과와 탐지 대상의 연결은 아직 구현하지 않았습니다.
HTTPS 실행과 탐지 상세는 [프론트엔드 탐지 안내](docs/frontend-detection.md)를 확인하세요.

아래 내용은 초기 API 기반 화면의 설계 기록이며 현재 화면의 기능과 다릅니다.

시각장애인의 물건 찾기를 돕는 모바일 웹의 초기 프론트엔드입니다.
React 19, TypeScript, Vite를 사용합니다. **이 저장소에는 백엔드와 YOLO 모델을 포함하지 않습니다.**

## 실행

Node.js 22.12 이상(현재 검증: 24.22.1)이 필요합니다.

```sh
npm ci
npm run dev -- --host 0.0.0.0
```

```sh
npm run build
npm run preview -- --host 0.0.0.0
```

## 백엔드 연결

`.env.example`을 참고해 `.env.local`을 만들고 별도 백엔드 주소를 설정합니다.
개발에서는 `API_PROXY_TARGET=http://127.0.0.1:8000`으로 Vite 프록시를 사용합니다.
직접 호출하거나 배포할 때는 `VITE_API_BASE_URL`을 설정하고 백엔드에서 프론트엔드 출처의 CORS를 허용합니다.
배포 환경에서는 같은 출처의 `/api`를 백엔드로 라우팅해도 됩니다. Vite 개발 프록시는 빌드 결과에 포함되지 않습니다.
`VITE_` 변수는 브라우저에 공개되므로 비밀값을 넣지 마세요. 환경변수 변경 후 개발 서버를 다시 시작하세요.

백엔드가 없으면 화면과 카메라·음성 안내는 사용할 수 있지만 분석 요청은 실패합니다.
가짜 탐지 결과를 생성하지 않습니다. API 초안은 [docs/api.md](docs/api.md)를 확인하세요.

## 현재 기능

- 컵·물병·휴대폰·책·리모컨 선택
- 후면 카메라 요청, 촬영, 카메라 종료 및 권한 오류 안내
- JPEG·PNG·WebP 사진 선택, 8MB 전송 제한, 20초 요청 제한
- 분석 API 호출, 응답 형식 검증 및 오류 표시
- 한국어 음성 안내, 다시 듣기, 음성 끄기, 스크린리더용 상태 알림

스마트폰 카메라에는 **HTTPS와 사용자 권한**이 필요합니다. 휴대폰에서 일반 HTTP LAN 주소로 접속하면 카메라가 제한될 수 있습니다.
브라우저와 기기에 따라 한국어 음성과 자동 음성 재생 지원이 다르므로 실제 기기 검증이 필요합니다.
사진 저장·보관 정책은 연결할 백엔드와 별도로 확정해야 합니다.
