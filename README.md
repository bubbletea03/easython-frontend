# 손길 · 물건 찾기 프론트엔드

React 19 · TypeScript · Vite 기반 모바일 카메라 앱입니다.

현재 화면은 [시안 1 · 상태 테두리](docs/status-frame-ui.md)를 적용합니다. 메인 물체는 초록 모서리와 20% 초록 배경, 나머지는 20% 흰 배경으로 표시하며 물체 박스에는 라벨을 붙이지 않습니다. 개발 컨트롤은 `#dev`에서만 표시합니다. 최신 수정 사항은 [사용성 수정 내역](docs/usability-fixes.md)을 참고하세요.

물체 탐지는 백엔드 YOLOE API를 우선 사용하고, 연결·모델 준비·탐지 오류 시 브라우저 MediaPipe로 대체합니다. 손 추적은 브라우저에서 처리합니다. 음성은 고정 녹음 → 서버 TTS → 브라우저 음성 순서로 대체합니다.

## 설정과 실행

Vercel 자동 배포는 [배포 설정 안내](docs/deployment.md)를 참고하세요. Vercel의 Git 연동으로 push마다 테스트·빌드·모델 자산을 검사한 뒤 배포합니다. GitHub Actions나 배포 Secrets 없이 Vercel에서 저장소를 연결하면 됩니다.

`.env.example`을 `.env.local`로 복사해 실제 백엔드 주소를 `BACKEND_API_URL`, 백엔드 API_KEY를 `BACKEND_API_KEY`에 설정하세요. `VITE_API_BASE_URL=/api`를 사용하면 키를 브라우저 번들에 넣지 않고 Vite/Vercel 서버에서 요청에 추가합니다. 실제 키는 커밋하지 마세요.

```powershell
npm.cmd ci
npm.cmd run dev -- --mode https --port 5173
```

휴대폰은 PC와 같은 Wi-Fi에서 출력되는 Network HTTPS 주소로 접속합니다. 기본 `/api` 프록시는 PC의 `http://127.0.0.1:8000`에 연결하므로 휴대폰의 루프백 주소를 사용하지 않습니다.

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview -- --mode https --port 4173
```

## 사용

- 시작을 누르면 카메라·음성을 준비하고 대기합니다. 찾을 물체를 말하기 전에는 탐지·안내·프레임 업로드를 하지 않습니다. 손 모델은 미리 불러오고 다음 탐색에도 재사용합니다.
- 마이크로 “컵 찾아줘”처럼 명령합니다. 최종 음성 인식 텍스트는 서버 `/parse`로 보내 해석하고, 응답의 targets를 탐색에 적용합니다. 명령 해석에 실패하면 오류를 안내합니다.
- 탐색 중에도 말하기 버튼으로 “어떻게 잡아?”, “어디 있어?”, 새 물체 요청, “그만”, “컵 잡았어”를 말할 수 있습니다. 별도 **그만** 버튼은 대기 중 요청도 취소합니다. 카메라 화면 터치는 탐색을 중단하지 않습니다.
- 같은 물체가 3초간 보이면 `/describe`를 백그라운드로 요청합니다. 선택 영역 이미지와 `target`을 보내고 서버 기본 프롬프트를 사용합니다. 추정 위치는 박스 비율로 물체 이동을 따라가며 응답 완료 후 10초 간격으로 다시 받습니다. 자동 요청 실패는 조용히 넘기고, 같은 위험은 찾기 작업당 한 번만 자동 안내합니다.
- 물체 중심이 화면 3×3 가운데 칸에 들어오면 손을 뻗도록 안내합니다. 손 안내의 화면 위·아래는 “앞으로·몸 쪽으로”입니다. 화면상 위치가 맞으면 “위치가 맞아요. 아직 닿지 않았다면 손을 조금 더 뻗어 보세요.”라고 말하고, 재생이 끝난 뒤 5초 동안 안내를 멈춥니다. 인식·좌표 갱신은 계속합니다. 화면 겹침만으로 완료 처리하지 않으며 사용자가 “잡았어요”라고 확인해야 완료합니다.
- 짧은 탐지 누락은 2초간 유지합니다. 놓침 안내는 6초 간격, 10초 뒤에는 다시 탐색 상태가 됩니다. 처음 찾는 동안 10초마다 진행을 알리고, 2분간 대상을 보지 못하면 탐색을 끝냅니다.
- 서버 탐지가 연속 3회 실패하면 기기 내 인식으로 전환하고 음성으로 알립니다. 지원되지 않는 물건도 알리고 5초마다 서버 복구를 확인합니다. Wake Lock 지원 환경에서는 카메라가 켜진 동안 화면 꺼짐을 방지합니다.
- 방향·발견·놓침 등은 ID로 로컬 녹음을 우선 재생하며 자주 쓰는 녹음을 미리 받습니다. 동적 TTS 결과는 메모리에 최대 32개·8MB까지 보관합니다. 손 방향 문장은 TalkBack이 중복 읽지 않고, 대기·처리·오류 상태는 별도 라이브 영역으로 전달합니다.

[API 연동·설정·검증 상세](docs/backend-integration.md) · [API 계약](docs/api.md) · [로컬 MediaPipe](docs/frontend-detection.md)

자동 TTS는 브라우저 정책에 따라 사용자 조작이 필요할 수 있습니다. 실제 거리·접촉은 측정하지 않습니다. 사진은 긴 변 640px·JPEG 품질 0.7로 전송하며, 명령 해석·설명은 백엔드에서 외부 모델을 사용할 수 있습니다.
