# frontend-review.md 수정 결과

2026-11-14 사용자 제공 리뷰의 10개 수정 요청과 기타 항목을 적용했다. 리뷰는 이전 스냅샷을 기준으로 작성되어, 이미 수정했던 경고 해제 동작도 이번 5초 제한·음성 우선순위 정책에 맞춰 통합했다.

| 리뷰 항목 | 적용 |
| --- | --- |
| 안전 경고 고착 | 경고 표시 최대 5초. 음성 종료·실패·취소 시 해제. 안전 음성에 높은 우선순위와 5초 제한을 두고 일반 잡기 설명은 뒤에 재생한다. |
| 점수 기준 | 서버 conf=0.25, 서버·로컬 화면 기준 0.35. 색 필터 후 점수를 0.65로 재차 버리지 않는다. |
| 전체 탐지 | DEFAULT_TARGETS 제거. 시작 시 targets 필드를 생략한다. 전체 모드는 박스만 표시하고 물체 발견·손 안내·자동 설명은 하지 않는다. |
| 색상 대안 | color_filter와 color_rejected를 보존한다. 3초간 불일치 시 dominant_color 등 검증된 색 이름으로 대안을 한 번 안내하고, 반복은 10초 이상 간격으로 제한한다. 알려지지 않은 색은 만들어 말하지 않는다. |
| 손잡이 추적 | 선택 물체 영역을 잘라 설명 API로 보낸다. 반환 좌표를 원본 이미지·대상 박스의 u,v 비율로 변환하고, 같은 추적 ID의 새 박스마다 위치를 재계산한다. 2.5초 만료는 제거했다. 대상 변경·미탐지에는 지운다. |
| 음성 통일 | 발견·방향도 speak() 사용. 고정 안내는 로컬 manifest/MP3 → 동적 /tts → 브라우저 음성 순으로 대체한다. /tts 제한 3초, 음성 요청 429는 지연 재시도하지 않는다. 안전 > 일반 > 방향 우선순위와 최대 3개 대기열을 사용하며 지난 방향은 쌓지 않는다. |
| 기본 프롬프트 | /describe에 prompt 필드를 보내지 않는다. 서버 prompt.txt를 사용하고 선택 영역 캡처로 대상 혼동을 줄인다. |
| 전송 크기 | 긴 변 최대 640px, JPEG 품질 0.7. 카메라 자체 해상도는 유지한다. |
| 잡기 성공 추정 | 같은 대상의 10% 확장 박스 안에 같은 손의 엄지·검지 끝이 1초 연속 머무르면 ‘잡으셨어요’ 안내 후 탐지를 멈춘다. 완료 화면은 화면 좌표 기준 추정임을 밝힌다. 손 이탈 또는 화면 터치 시 전체 탐지를 재개한다. |
| 컵/보울 비율 | 가로세로 비율 강제 분류를 삭제하고 로컬 모델의 원래 클래스를 사용한다. |
| 녹음 시작 효과음 | 효과음이 끝난 뒤 250ms 시점에 음성 인식을 시작한다. 대기 중 취소·중지·탭 숨김·언마운트 시 타이머를 정리한다. |
| Vercel 키 노출·중계 | /api를 Vercel Function으로 중계한다. BACKEND_API_URL·BACKEND_API_KEY는 서버 전용이며 VITE_API_KEY 없이 동작한다. 로컬 .env.local도 같은 방식으로 전환했다. |

## 검증

- API, 취소, 좌표, 자동 요청, 색 안내, 잡기 겹침, 캡처 크기, 서버 중계, 음성 종료·대기열·고정 음성 우선 테스트 41개 통과.
- TypeScript/Vite 빌드와 모델·WASM·서체·음성 자산 282개 검사 통과. 현재 서버 manifest는 266개 녹음(약 15.2MB)을 제공하며 전부 다운로드해 포함했다. 빌드 시 외부 음성을 요구하지 않는다. 실제 BACKEND_API_KEY가 브라우저 번들에 없음을 검사했다. 키 없이 브라우저 기기 ID만 보낸 로컬 HTTPS /api/health 중계도 실제 HTTP 200을 확인했다.
- 실제 백엔드: /health, targets 없는 이미지 업로드(mode=all), 한국어 /parse, prompt 없는 /describe HTTP 200. 공개 Ultralytics 샘플 이미지로 실제 탐지와 purple bus의 color_rejected[].dominant_color=blue 응답을 확인했다. 빈 이미지 검증 결과를 실제 물체 탐지 성공으로 취급하지 않았다.
- Chrome 360×780·320×568 테스트: 테스트 전용 카메라/손/음성 인식/API 응답으로 전체 탐지 무음, 0.4 점수 표시, 녹음 시작 지연, 3초 자동 설명 한 번, 경고 해제, 좌표 지속·이동, 1초 겹침 완료, 손 이탈 재탐지, 색 대안 음성, 가로 넘침 없음·런타임 오류 없음을 확인했다. 이 테스트 더블은 제품에 포함하지 않는다.

## 배포와 한계

- Vercel에는 코드 push와 서버 환경변수 등록 후 새 배포가 필요하다. VITE_API_BASE_URL=/api, BACKEND_API_URL=실제 공개 HTTPS 주소, BACKEND_API_KEY=현재 키를 설정하고 기존 VITE_API_KEY는 제거한다. 로컬 변경만으로 운영 배포가 바뀌지 않는다.
- 중계는 키를 숨기며 로그인이나 사용자별 인증을 대신하지 않는다. 백엔드의 요청 제한을 유지한다.
- 좌표는 2D 추정이다. 가림·모델 오인·카메라 이동은 추적 ID와 위치를 바꿀 수 있다. 실제 접촉·물리적 거리·손잡이의 안전한 파지를 보장하지 않는다. 실제 휴대폰 권한, 음성 녹음 누설, 음성 재생·진동과 실물 파지는 기기에서 확인해야 한다.
- 오래된 시안/연동 문서의 수치보다 이 문서와 현재 코드가 우선한다.
