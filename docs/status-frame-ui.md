# 시안 1 · 상태 테두리

현재 사용 흐름은 [사용성 수정 내역](usability-fixes.md)과 [README](../README.md)를 따른다.

## 시작과 조작

시작 버튼을 누르면 카메라와 음성을 준비한다. 준비 완료·실패 사유는 음성과 상태 라이브 영역으로 전달한다. 대기 중에는 대상 인식·프레임 업로드를 하지 않고 손 모델만 미리 준비한다.

말하기 버튼은 대기 중에는 음성 입력을 받으며 탐색·손 안내·요청 처리 중에는 그만으로 바뀐다. 누르면 진행 중 요청과 안내를 취소하고, 다시 누르면 새 음성 입력을 받는다. 별도 그만 버튼과 화면 전체를 누르는 정지 동작은 없다.

탐색 중에는 별도의 계속 듣기를 유지한다. 앱 안내와 5초 무음 중에도 그만은 즉시 감지하고 서버 없이 중지한다. 무음·인식 종료는 자동 재시작하며, 페이지 숨김·중지 시 해제한다. 계속 듣기는 손 안내를 녹음 화면으로 바꾸지 않는다. 권한 거부·지원 불가·반복 오류는 사용자에게 알리고 버튼 중지를 유지한다.

## 표시와 안내

- 상태는 대기, 듣기, 처리, 탐색, 발견, 손 안내, 놓침, 실제 위험 경고, 사용자 확인 완료로 구분한다.
- 메인 물체는 초록 모서리와 반투명 초록 배경, 다른 물체는 흰 윤곽선이다. 물체 라벨은 박스에 표시하지 않는다.
- 색·글자·간격은 `src/tokens.css`의 Figma 토큰을 쓴다. 상태색은 탐색 파랑, 발견·손 안내 초록, 놓침 앰버, 위험·오류 빨강이며 테두리·상태 칩·오버레이가 같은 색을 쓴다. 색만으로 상태를 전달하지 않는다.
- 상단 단계 표시는 찾기·맞추기·손 뻗기 중 현재 위치를 보여 준다(`SceneUI.step`). 놓치면 찾기로 돌아간다.
- 발견 후 가운데가 아니면 3×3 격자의 가운데 칸을 모서리로 표시한다. 손 안내 중에는 검지 끝에서 목적점까지 점선과 목적점 링을 그린다. 링은 화면상 간격에 따라 세 단계로 줄어들 뿐 거리 수치나 접촉을 뜻하지 않는다.
- 놓치면 마지막으로 보인 쪽 화면 가장자리에 방향 표시를 띄운다. 방향을 모르면 양쪽에 띄운다.
- 발견·놓침·위치 맞음으로 바뀔 때 지원 기기에서 한 번 짧게 진동한다.
- 카메라 오류 때 버튼은 다시 시도로 바뀌어 카메라를 다시 켠다.
- 가장 큰 손 하나만 표시·안내한다.
- 물체 중심이 화면 3×3 격자의 가운데 칸에 들어온 뒤 손을 뻗도록 안내한다. 밖에서는 폰의 상하좌우 방향을 안내한다.
- 손 안내는 왼쪽·오른쪽·앞으로·몸 쪽으로다. 폰 안내는 폰을 명시한다.
- 손과 물체의 화면상 위치가 맞으면 위치가 맞아요. 아직 닿지 않았다면 손을 조금 더 뻗어 보세요라고 말한다. 이 안내가 끝난 뒤 5초간 음성·효과음·진동을 멈추고 인식·좌표 갱신은 계속한다. 이후 최신 상태로 안내한다.
- 화면 겹침을 실제 접촉이나 완료로 판단하지 않는다. 잡았어요라는 사용자의 확인으로만 완료한다.

## 탐지와 복구

트랙을 3초간 보관하며 2초 미만 누락은 같은 대상으로 이어 안내한다. 손이 목표 근처를 가리면 놓침 안내를 억제한다. 놓침 안내는 6초 간격이고, 10초 이상 놓치면 탐색 상태로 돌아간다. 처음 찾는 중에는 10초마다 진행을 알리고 2분 미탐지 시 탐색을 끝낸다.

서버 탐지가 3회 연속 실패하면 대체 인식·지원 제한을 음성으로 알리고 5초마다 서버 복구를 확인한다. 카메라가 켜진 동안 지원 브라우저에서 Wake Lock을 유지한다.

## 설명과 그립 포인트

같은 물체가 3초간 보이면 백그라운드로 /describe를 요청한다. 자동 요청은 손 안내나 화면을 처리 상태로 바꾸지 않는다. 선택 영역에 각 방향 25% 여백을 둔 이미지와 실제 target 이름을 보내며 confidence·위험 규칙을 명시한다. 잡는 법은 저장했다가 손 뻗기 안내 뒤 실제 손 안내가 시작될 때 한 번만 말한다.

포인트는 물체 박스에 대한 비율로 저장하여 프레임마다 위치·크기 변화를 따라가며, 응답 완료 후 10초 간격으로 좌표를 다시 받는다. 대상 변경·오래된 누락·중지 시 요청을 취소하고 늦은 응답을 무시한다. 실패·낮은 신뢰도는 자동 음성으로 반복하지 않는다. 수동 설명 요청은 진행 상태와 오류도 안내한다.

명확한 위험은 안전 경고로 재생하며 같은 위험은 찾기당 한 번만 자동 안내한다. 경고는 재생 종료·실패·취소 시 해제한다. 안전 경고와 상태 안내를 제외한 방향 글자는 TalkBack이 자동으로 중복 읽지 않는다. 실제 거리와 접촉은 측정하지 않는다.

서버 결과는 신뢰도 0.5 이상을 사용한다. 정확한 이름 일치·신뢰도·크기 순으로 대상을 고른 뒤 1초 넘게 놓치기 전에는 바꾸지 않는다. 정확 일치 후보가 비슷한 두 물건이면 좌우를 묻고 계속 듣기로 답을 받는다. 답이 없으면 질문 종료 후 5초 뒤 큰 쪽을 선택한다. #dev에서 실제 탐지 이름과 최근 5개의 음성 종료 기록을 확인한다.
