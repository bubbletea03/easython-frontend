# 시안 1 · 상태 테두리

현재 동작은 `FE-희찬수정안-1553.md`를 반영한다. 이전 계속 듣기·중앙 칸 강제 유지 규칙은 사용하지 않는다.

## 시작과 음성 입력

시작 버튼에서 카메라와 Web Audio를 준비한다. 대기 중에는 탐지·프레임 업로드·마이크를 사용하지 않고 손 모델만 미리 준비한다.

버튼을 누르면 한 번 듣는다. 탐색 중에는 안내·비프·자동 요청을 즉시 멈추고 대상 정보를 보관한 채 듣는다. 말이 없으면 5초, 전체 입력은 최대 6초이며 자동 재시작은 없다. 듣는 중 다시 누르면 바로 입력 종료를 요청한다. Android 시스템 시작음과 겹치는 앱 녹음 효과음은 사용하지 않고 종료 때 짧은 진동만 준다.

- 그만·무음·인식 실패: 멈춤을 유지하고 안내를 멈췄어요로 대기
- 잡았어: 잡으셨군요. 안내를 마칠게요와 확인 진동 후 대기
- 어떻게 잡아: 현재 대상의 잡는 법 한 문장 후 손 안내 재개
- 다른 물건: 새 탐색

## 폰·손 안내 단계

조준에서는 좌우 폰 안내만 하며 440Hz 효과음으로 손 안내와 구분한다. 물체 중심의 가운데 1/3 진입·가장자리 15% 이탈 여유를 두며, 가운데에 0.5초 머물거나 손이 0.5초 보이면 손 단계로 잠근다.

손 단계 시작에는 폰은 그대로 두고, 손만 움직여 주세요라고 한 번 말한다. 이후 물체가 가운데 칸을 조금 벗어나도 왼쪽·오른쪽·앞으로·몸 쪽으로 손 안내만 한다. 좌우 가장자리 10%를 넘으면 손은 그대로 두고 폰을 돌리라고 전환을 먼저 알린다. 25~75% 안으로 돌아오면 다시 손을 안내할게요라고 재개한다. 2초 놓침은 다시 조준한다.

화면상 목표 위치에 맞으면 한 번만 거기예요. 그대로 쭉 뻗어 잡으세요. 잡으셨으면 버튼을 누르고 잡았어라고 말해 주세요와 [80] 진동을 보낸다. 안내 종료 후 5초 무음은 유지하고 동일 문장은 반복하지 않는다. 벗어났을 때만 방향 안내와 비프를 재개한다. 실제 완료는 사용자의 잡았어 확인으로만 처리한다.

## 날카로운 대상

knife·scissors·razor·nail clipper 및 한국어 이름 또는 AI sharp 위험은 손잡이 확인 전 박스 중앙으로 안내하지 않는다. 손잡이를 바로 요청하고 손을 잠시 멈추도록 안내한다.

박스 긴 축에서 손잡이 반대쪽 절반을 칼날 쪽으로 추정한다. 검지·엄지 끝 중 하나가 10% 여유를 둔 이 구역에 0.3초 머물면 최우선 음성, [400,150,400] 진동, 빨강·검정 경고를 표시한다. 손잡이 방향은 손끝 기준으로 말한다. 반복은 최소 4초 간격이며 같은 경고 음성이 재생 중이면 중간에 끊어 다시 시작하지 않는다. 손이 벗어나면 경고를 해제한다.

이 구역은 카메라 영상의 근사 영역이다. 실제 칼날 위치나 접촉을 확정하지 않으며, 기울어진 물체·가려짐은 실기기 확인이 필요하다. 대상 외의 위험 물체는 이번 범위에서 탐지하지 않는다.

## 탐지·설명·표시

가장 큰 손 하나를 사용한다. 서버 탐지는 신뢰도 0.5 이상에서 정확 일치·점수·크기로 고른 뒤 고정한다. 1초 이상 놓치기 전에는 다른 대상으로 바꾸지 않는다. 비슷한 두 후보의 좌우 답변도 버튼을 누르고 말한다.

설명 사진은 25% 여백을 포함하고 실제 target과 confidence 규칙을 보낸다. 자동 설명은 실패를 조용히 무시하며 잡는 법은 손 안내 시작 후 한 번만 말한다. 그립 포인트는 박스에 붙여 따라가고 10초 간격으로 새로 받는다. 멈추고 듣는 동안 서버 탐지 업로드와 자동 설명을 잠시 중단하며 대상 트랙은 보관한다.

메인 물체는 초록 모서리·반투명 초록 배경, 다른 물체는 반투명 흰 배경으로 표시한다. 일반 방향 글자는 TalkBack이 중복 읽지 않고 대기·처리·오류는 별도 라이브 영역으로 전달한다. #dev에서 실제 이름, 안내 재생 경로, 입력 켜짐 여부, 음성 종료 기록을 확인한다.
