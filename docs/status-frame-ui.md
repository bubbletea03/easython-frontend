# 시안 1 · 상태 테두리 적용

사용자가 제공한 `시안1_상태테두리.html`의 앱 화면·디자인 토큰을 적용했다. 시안 설명용 웹 문서의 표·휴대폰 외곽 모형·가짜 OS 상태 표시줄은 제품 화면에 넣지 않았다. 카메라 영상도 시안의 정지 사진으로 대체하지 않는다.

## 적용

- 노랑 #FFD400, 잉크 #0B0B0C, 흰색. 실제 안전 문장 수신 시에만 경고 빨강 #FF453A와 카드 바탕 #9B1C14 사용.
- 시안에 포함된 Pretendard 서브셋 500/600/700/800 및 Material 아이콘 경로를 추출해 로컬 자산으로 사용.
- 노란 시작 화면 전체 버튼. 시작 전 카메라를 요청하지 않으며 누른 뒤 카메라·선택적 오디오 피드백을 준비하고 기본 물체 탐지를 자동 시작한다. 백엔드 우선, 연결 실패 시 MediaPipe 대체이며 음성 명령으로 탐색 대상을 바꾼다.
- 대기에는 테두리 없음. 듣기·처리·탐색·안내 중 4px 노란 테두리. 위험 시 6px 빨강, 놓친 방향은 16px. 깜박임 없음.
- 좌상단 52px ‘그만’ 버튼과 16px 상태 알약. 하단 92px 말하기 원, 14px 이름, 24px 한 줄 안내. 사용자 화면에는 입력창·찾기·설정·재연결·설명 버튼 없음.
- 카메라 화면 어디를 눌러도 음성 인식. 말하기/그만 버튼은 키보드와 스크린리더로 사용 가능. 듣는 동안 노란 고리 3개와 흰색 ‘들은 말’ 말풍선.
- 흰색 2px 인식 상자와 검은 이름표. 이전의 초록 면·모서리 프레임·정확도 %·빨간 손끝 빛 번짐 제거.
- 손 뼈대는 62% 흰색, 검지 끝을 흰 고리로 강조. 실제 서버 handle_point만 노란 점/목표 고리로 표시. 점선·3×3 격자 없음.
- 음성 입력 시작/종료음, 선택적 진동, 화면상 손 이동 방향에 따른 스테레오 비프. API/기기 미지원 시 핵심 흐름을 막지 않는다. 숨겨진 탭·발화 중에는 안내 비프 중지.
- 개발용 상태·기존 재연결/설명 컨트롤은 주소의 `#dev`에서만 표시.

## 상태 연결과 한계

`sceneUI.ts`에서 대기·듣기·처리·탐색·발견·손 안내·놓침·재질문·안전 경고·완료·카메라 오류를 실제 상태로 계산한다. 시작은 카메라 전 별도 화면이다. 음성 최종 텍스트 → `/parse` → targets 탐색 흐름을 유지한다. 이해하지 못한 명령은 재질문 화면으로 전환하며 이전 탐색을 중지한다.

놓침은 마지막 탐지 후 2초, 장시간 미탐지는 탐색 시작 후 30초 기준으로 안내한다. 반복 손 안내 TTS 간격은 최소 1.5초이며 말하기 중에는 멈춘다. 물체 발견 안내는 기존 1초 유지 조건을 따른다.

시안의 ‘팔 닿는 거리’, ‘거기예요. 그대로 쭉 뻗어 잡으세요’, ‘엄지·검지가 박스 안에 있으면 잡기 성공’은 2D 화면만으로 검증할 수 없어 실제 거리·접촉·성공 판정으로 구현하지 않았다. 화면에서 겹칠 때는 ‘화면에서 겹쳐 있어요’로 안내한다. 완료 체크 화면은 사용자가 **‘잡았어요’라고 명시적으로 음성 확인**했을 때만 표시한다. 안전 경고는 서버가 실제 반환한 safety 문장만 사용한다.

handle_point는 이전과 같이 전체 사진 좌표를 화면으로 변환하며 오래된 좌표를 고정 안내하지 않도록 최대 2.5초 후 제거한다. 서버 설명 기능이 비활성화되어 있으면 시안처럼 임의의 손잡이 점이나 경고를 생성하지 않는다.

안전 경고 상태는 설명 음성의 재생 종료 시 해제되어 현재 물체 탐지·손 안내 화면으로 복귀한다. 서버 오디오 실패 후 브라우저 음성으로 대체되면 대체 음성이 끝날 때 해제한다. 재생 취소·최종 재생 실패 시에도 해제하며, 브라우저가 종료 이벤트를 보내지 않는 경우 최대 60초 제한을 둔다. 이전 안내의 늦은 종료 이벤트는 새 요청의 경고 상태에 영향을 주지 않는다. 탐색 대상과 실행 상태는 유지한다.

백엔드 탐지와 설명 기능이 준비된 상태에서는 현재 선택된 물체가 3초간 연속 인식되면 `/describe`를 자동으로 한 번 호출한다. 음성 입력·명령 처리·탭 숨김·미탐지·대상 변경 시 3초 대기를 초기화하며, 같은 탐색 세션에서 이미 요청한 추적 ID는 자동 재요청하지 않는다. 수동 설명 요청도 자동 중복 호출을 억제한다. 실패 시 자동 무한 재시도하지 않으며 사용자는 음성으로 다시 설명을 요청할 수 있다. 대상 이탈·변경·탐색 중지 시 진행 중인 설명 요청을 취소하고 이전 대상의 응답을 표시하지 않는다. 로컬 MediaPipe 대체 탐지 중에는 자동 설명을 요청하지 않는다.

## 검증

- API/좌표/상태 로직 테스트 16개 및 TypeScript/Vite 빌드.
- Chrome에서 360×780, 320×568 뷰포트로 테스트. 시안 사진을 테스트 전용 카메라 스트림으로 공급하고 음성 인식·서버 응답·손 좌표를 테스트 더블로 주입해 화면 전환 검증. 실제 제품에는 테스트 사진·좌표를 넣지 않음.
- 시작 전 video 없음, 대기 테두리 없음, 듣는 말풍선·고리, 탐색/손 안내, 실제 응답 필드의 포인트·경고, 중지, 놓침, unknown, 사용자 확인 완료 화면을 확인. React 런타임 오류 및 가로 넘침 없음.
- 모델·WASM·서체가 배포 출력에 포함되는지 자산 검사. 실제 휴대폰 카메라·마이크 권한, 자동 음성 재생, 진동·좌우 비프는 기기 검증이 필요하다.
